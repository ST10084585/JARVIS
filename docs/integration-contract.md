# Integration API

Imports are lazy: importing modules never opens audio devices or launches browsers.

`SpeechService(model_path: Path)` exposes `devices() -> list[dict]`, `listen(cancel: threading.Event, seconds=12, device=None) -> str`, `speak(text, cancel=None)`, `stop()`, `transcribe_wav(path) -> str`. Call blocking listen/speak on the job thread. Push-to-talk is bounded to 30 seconds maximum. Missing model raises FileNotFoundError. stop cancels active speech/listening. Each operation releases its model/device/COM resources. WAV must be mono 16-bit PCM. No wake word/background mic.

`BrowserSession(profile_dir: Path).read(url, cancel=None) -> {title,text,url}` fetches only public HTTP(S) destinations with DNS address pinning, validates every redirect, limits 2 MiB response and 20 seconds total socket budget, then extracts in an ephemeral headless Playwright browser with scripts/network disabled. Does not attach to a user's browser. `replay(steps, approved=False, cancel=None)` accepts at most 30 `navigate`, `read`, or `extract` actions with explicit URL; rejects all clicks, selectors, scripts and submissions even when approved. Returns `{results: [...], completed: n}`. Review is required (`approved=True`) for replay.

`WatchLearn(profile_dir: Path)` exposes `start(url, consent=False)`, `pause()`, `resume()`, `annotate(text)`, `stop() -> list`, `events() -> list`, `delete()`, `to_workflow() -> dict`. start returns after launching its owning thread; inspect `.error` for browser launch/navigation failures, `.running` for state. Separate visible browser uses temporary context. It only permits GET public HTML/text documents; blocks all subresources, scripts, forms and POST. No account cookies imported or saved. It records top-level navigation and generic click tag metadata (no typed values or page labels). URLs lose query/fragment; credential-sensitive paths are omitted. Annotations are explicit user text (do not include secrets). Events persist to profile/watch/events.json, capped at 1,000. Pause/stop gates capture synchronously. stop joins the owner thread up to 25 seconds; production page loads have 20-second cap. Workflow export is a review-required draft of navigation steps; click events become unsupported review notes, never executable clicks. This conservative mode is for public website demonstrations, not logged-in app automation.

# Workflow API

`SkillLibrary(profile_dir)` persists skills in workflows.sqlite3. list/get return id, name, description, definition, version, enabled. save creates/enables a local skill; editing resets review (disabled). Imported skills are always disabled; set_enabled records explicit review. versions and rollback preserve history. export_skill/import_skill use JSON only.

Definition schema: `{"schema_version":1,"steps":[{"op":"strip","columns":["Name"]}],"formula_policy":"escape"}`. formula_policy is escape (default) or reject, never allow. Operators select/strip/upper/lower/drop_blank/drop_duplicates/sort require nonempty columns list; rename requires mapping object. sort accepts descending boolean. No paths/code are permitted in definitions. CSV UTF-8 and XLSX first worksheet supported; string operations reject numeric Excel cells. All file paths must be absolute, local and without parent traversal or symlink/junction ancestors. Caller must authorize exact input/output paths before execute; this module does not grant folder permission. Original and existing outputs never overwritten. Output is published atomically with exclusive creation.

`execute(definition,input_path,output_path,cancel=None)` returns output_path, rows, columns, escaped_cells; cancellation Event raises CancelledError. `infer_csv(input_path,expected_path)` returns a validated candidate definition only for unambiguous per-column identity/strip/upper/lower/strip+case transforms with unchanged row count; it rejects unknown mappings and ambiguity. Review before saving.

`JobManager(profile_dir)` submit(label, fn)->id; fn(cancel_event,progress_callback) returns JSON-serializable result. list returns id,label,status,progress,result,error. cancel, pause, resume, shutdown. One worker; pause gates queued jobs, running jobs use cooperative cancellation. Interrupted jobs become interrupted after restart and are never replayed automatically.

`Scheduler(profile_dir,jobs,run_skill=None)` supports durable reminders only. add(label,due_iso,interval_seconds=0,skill_id=None,input_path='',output_path='')->id rejects skill_id (unattended skill permission binding is deliberately unsupported). Use timezone-aware ISO dates. list/remove/tick; caller calls tick every 10 seconds. notifications contains newly due dicts (id,label,due); pop or clear after presentation. Durable reminder history is also recorded as completed jobs. Missed repeating reminders coalesce to one occurrence. No folder monitor.

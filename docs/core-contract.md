# Core API contract

`Store(profile_dir: Path)` exposes the requested settings/chat/memory/audit/backup methods. `profile_dir`, `workspace` (profile_dir/workspace), `db_path` are public Paths. SQLite WAL, foreign keys, and a reentrant connection lock protect same-process threads; each mutation commits. `chats` includes archived entries; UI filters as desired. Memory is explicit opt-in per saved fact, with `memory_enabled` setting default true. Nothing automatically extracts memories. `backup(path)` creates a standalone SQLite snapshot (does not include skills or files), refuses overwrite.

`ToolRegistry(store).list()` returns descriptors `{name, description, parameters, approval, unattended}`. `execute(name, args, approved=False, unattended=False, cancel=None)` returns a dict or raises ValueError, PermissionError, FileExistsError, InterruptedError, or `ApprovalRequired(description)`. Paths are relative to profile workspace unless absolute. Workspace and settings `authorized_roots` are the only roots; authorization never bypasses path policy. No reparse points, UNC, device names, alternate streams, or output overwrites. Write actions outside workspace require approval and are prohibited unattended. No shell command string is accepted.

Tools: `time {}`, `system_info {}`, `find_files {path?:str, pattern?:str}`, `read_document {path:str}`, `write_note {path?:str, text:str}`, `copy_file {source:str,destination:str}`, `make_directory {path:str}`, `open_notepad {}`, `network_check {}` (approved explicit network diagnostic), `powershell_diagnostic {diagnostic:'processes'|'disks'|'os'}`. `open_notepad` requires approval and forbids unattended execution. Diagnostics are fixed commands only. PDF, DOCX, XLSX, CSV and UTF-8 text extraction uses lazy imports; output and input size are bounded. Tool auditing records names/status only, never document content.

`OllamaClient(model='qwen3:0.6b', mode='Eco')`: `models()->list[str]`, `stream(messages,cancel=None)->Iterator[str]`, `unload()`, `pull(name,progress=None)`, `delete(name)`, `benchmark()->dict`. HTTP endpoint is fixed loopback 127.0.0.1:11434, proxies disabled, redirects rejected. Stream cancellation closes the response; pre-cancelled calls never load a model. Generation serializes across Windows profiles with a named mutex. Eco keep_alive=0, Balanced=60s, Performance=5m. Context=2048, output=512, thinking disabled. Model installation is an explicit caller action requiring internet via Ollama. Methods raise honest errors; no paid fallback or fabricated responses. Benchmark invokes real inference and returns elapsed seconds, character count, and model.
